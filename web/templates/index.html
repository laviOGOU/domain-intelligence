Saisis un nom de domaine : Domain Intelligence interroge le registre RDAP, le DNS, la géolocalisation de l'adresse IP et le certificat TLS, puis attribue un score de risque argumenté sur 100. Chaque analyse est conservée pour être comparée plus tard.

Étape 1

Saisir le domaine

Un nom seul, une URL complète ou une adresse e-mail — seul le domaine est conservé.

Étape 2

Croiser les sources

Registrar, pays d'hébergement, âge, expiration, serveurs de noms et certificat.

Étape 3

Lire le score

15 règles pondérées donnent un niveau faible, modéré ou élevé, avec le détail de chaque point.
